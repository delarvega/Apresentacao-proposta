2. COMO RODAR LOCALMENTE
============================================================

Opção A - Duplo clique:
1. Navegue até a pasta C:\Users\Thiago Vega\Programas App\
2. Dê duplo clique em "index.html"
3. O site abrirá no seu navegador padrão

Opção B - Via linha de comando:
1. Abra o PowerShell ou CMD
2. Digite: cd "C:\Users\Thiago Vega\Programas App"
3. Digite: start index.html
   ou: python -m http.server 8000
   Depois acesse: http://localhost:8000

3. ALTERANDO AS IMAGENS
============================================================

Todas as imagens estão na pasta assets/ e podem ser substituídas facilmente:

- Para trocar o avatar: substitua o arquivo assets/avatar.png por uma nova imagem
- Para trocar a capa do Facebook: substitua assets/capafacebook.png
  * A imagem deve conter ambos os layouts (desktop e mobile) ou será cortada proporcionalmente
- Para trocar templates Instagram: substitua assets/instagram.png
- Para trocar o mockup do website: substitua assets/website.png
- Para trocar o logo: substitua assets/logo.png

As imagens têm dimensões recomendadas:
- avatar.png: 512x512px (quadrada)
- capafacebook.png: 2250x630px (desktop) / 1080x1920px (mobile)
- instagram.png: 1080x1080px (post) / 1080x1920px (story)
- website.png: 1400x800px (aproximado)
- logo.png: 40x40px (óptimo)

4. COMO PUBLICAR NO NETLIFY (Para cliente visualizar online)
============================================================

Passo a passo para publicar este site e compartilhar o link:

1. Crie uma conta em https://www.netlify.com (gratuita)
2. No painel da Netlify, clique em "New site from Git"
3. Escolha "Upload a build file"
4. Faça upload da pasta inteira (ou zip) contendo:
   - index.html
   - pasta assets/
5. Clique em "Deploy site"
6. Após o processamento, a Netlify gerará um link do tipo:
   https://seu-site-xxxxx.netlify.app

5. COMPARTILHANDO COM O CLIENTE
============================================================

O link gerado pode ser compartilhado diretamente. O cliente poderá:
- Visualizar o mini-site em qualquer dispositivo
- Navegar entre as seções pelo menu fixo
- Ver todas as seções da identidade visual desenvolvida
- Ver o pacote completo de entrega

8. ANIMAÇÕES
============================================================

O site possui animações suaves:
- Fade-in: elementos aparecem gradualmente

- Delay diferenciado por seção (0.1s a 0.5s)

9. PERSONALIZAÇÕES ADICIONAIS
============================================================

Para ajustes finos no CSS, edite o bloco <style> no index.html:

- Alterar cores: modify as variáveis :root no topo
- Alterar espaçamento: modify os valores de padding/margin
- Alterar animações: modify as keyframes @keyframes
- Alterar responsividade: modify as media queries (já incluídas implicitamente)

============================================================
DÚVIDAS COMUNS
============================================================

Q: O site não carrega as imagens?
R: Verifique se os nomes dos arquivos na pasta assets/ correspondem
  aos usados no HTML (src="assets/arquivo.png")

Q: Quero mudar a paleta de cores?
R: Edite as variáveis --vermelho-principal, --cinza-escuro, etc.
  na seção :root do CSS

Q: Como adicionar mais páginas?
R: Este é um site de uma única página (single page). As âncoras
  do menu já conectam todas as seções. Basta adicionar mais
  <section> no corpo do HTML.
